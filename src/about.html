About me and this project

A student working at the intersection of security, software and cloud infrastructure.

Who I am

I'm a computing student based in Dallas, Texas. My coursework and personal projects focus on cybersecurity, digital forensics and building practical web applications with Python and JavaScript.

I like projects where security is part of the design from the start rather than added at the end. That includes building a forensics lab, writing a malware-detection web app, and deploying sites like this one with least-privilege access and secrets kept out of source code.

Why this site exists

This website is Project 2 of my cloud computing course. The goal is a real, public website, and more importantly a working demonstration of the cloud ideas we studied:

  • Consumption-based pricing (OpEx): no upfront hardware, only pay-per-use, kept on free tiers.
  • Shared responsibility: Microsoft runs the datacenters, network and hosts; I own the code, content, accounts and identities.
  • Scalability: the global edge network absorbs traffic spikes automatically.
  • Monitoring: Azure Monitor, Application Insights and Service Health alerts.

Shared responsibility on this site

Azure Static Web Apps is a PaaS offering, so responsibility is split as follows.

LayerResponsibleHow it's handled here
Physical datacenter, network, hostsMicrosoftAzure's global infrastructure
Operating system & runtime patchingMicrosoftManaged by the PaaS platform
TLS certificatesMicrosoftFree, auto-renewing SSL
Application code & contentMeReviewed in GitHub, deployed by CI/CD
Secrets & configurationMeStored in application settings, never in code
Accounts & identitiesMeMFA, least-privilege access, single owner
Data (contact messages)MeValidated input, private storage account
