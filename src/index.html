How this site runs

The site demonstrates the main cloud computing ideas from the course, applied to a real deployment.

PaaS

Azure Static Web Apps

Pages are served from Microsoft's global edge network with a free, auto-renewing SSL certificate. There are no virtual machines to patch.

Serverless

Azure Functions

The contact form posts to a function that runs only when called and saves each message to Azure Table Storage.

CI/CD

GitHub Actions

Work happens on a feature branch. Merging into main builds and deploys the site automatically.

Monitoring

Application Insights

Requests, failures and response times from the API are tracked in Azure Monitor. Service Health alerts flag platform outages.

Security

Least privilege

HTTPS only, secrets kept in app settings rather than code, strict security headers, and access limited to my own accounts.

OpEx

Pay for what you use

Everything runs on free or low-cost tiers. There is no upfront hardware cost, and a budget alert in Cost Management watches spending.
